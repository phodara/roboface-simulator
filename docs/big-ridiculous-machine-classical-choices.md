# Big Ridiculous Machine Awakens

Classical music candidates for Vidiotbox.

A short list of powerful classical pieces that could soundtrack a dramatic text crawl, a fake cosmic initiation, or any other useful misuse of grandeur.

## O Fortuna From Carmina Burana - Carl Orff

Vibe: Huge, ominous, instant drama.

Use note: The composition is still copyright-sensitive in many places, so it is harder to use safely.

## Dies Irae From Verdi's Requiem

Vibe: Thunderous choir and orchestra; very apocalypse-crawl friendly.

Use note: Composition is public domain, but the recording still needs a usable license.

## Toccata And Fugue In D Minor - J.S. Bach

Vibe: Gothic, theatrical, instantly recognizable.

Use note: Usually easier to find public-domain or freely licensed recordings.

## Mars, The Bringer Of War From The Planets - Gustav Holst

Vibe: Menacing, mechanical, marching doom.

Use note: Composition is public domain in the U.S.; recordings still need checking.

## Night On Bald Mountain - Modest Mussorgsky

Vibe: Chaotic supernatural energy.

Use note: Powerful but a little mischievous, which fits Vidiotbox nicely.

## Recommendation

Best maximum-seriousness choice: Verdi's Dies Irae.

Best powerful-but-weird choice: Night on Bald Mountain.
